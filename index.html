Die Idee

Ein Spiegel, der weiß, wann er still sein muss

Herkömmliche Alarm-Anzeigen kennen nur an oder aus. Dieses System denkt in Situationen: Es zeigt immer nur die eine gerade wichtigste Information — und ordnet sich dem Einsatz unter, ohne die Familie mit Technik zu überladen.

Bausteine

Zwei Module, die miteinander sprechen

Beide sind eigenständig nutzbar und kommunizieren über eine schlanke Notification (APAGER_STATE). So bleibt jedes Modul wartbar — und das Zusammenspiel trotzdem nahtlos.

MMM-aPagerAlarm

Das Einsatzfenster

Empfängt die Alarmierung und führt durch vier Phasen — vom akuten Alarm bis zur wertschätzenden Rückkehr.

  • Zentriertes Alarmfenster mit Blaulicht & Ton
  • Ruhige Karten „ist im Einsatz“ / „war im Einsatz“
  • Webhook-Server auf Port 8090
  • Sendet Phasenwechsel an andere Module & Home Assistant
MMM-SmartCompliments

Der Familienassistent

Zeigt kontextabhängig genau eine Botschaft — nach Uhrzeit, Wochentag, Wetter, Kalender, Geburtstagen und Einsatzstatus.

  • Prioritäts-Engine statt Zufallssprüche
  • Geburtstage, Hochzeitstag, Feiertage, Countdown
  • Danke-Nachwirkung nach dem Einsatz
  • Manueller Ein-/Aus-Schalter auf Port 8091

Vier Phasen, ein roter Faden

Steuerung

Alles über einfache URLs

Jede Aktion ist ein Aufruf — per Browser-Lesezeichen, NFC-Tag an der Tür oder Automation. Kein Konto, keine App.

MethodeEndpunktWirkungPort
POST/GET/alarmAlarmierung auslösen (Phase 1)8090
POST/GET/homeSofort in Phase 3 springen8090
POST/GET/clearEinsatz sofort beenden8090
GET/apager/healthStatusprüfung8090
POST/GET/compliments/offKompliments ausblenden8091
POST/GET/compliments/onKompliments einblenden8091
POST/GET/compliments/toggleUmschalten8091
Ports merken: 8080 gehört MagicMirror selbst — nie belegen. 8090 = Einsatzfenster, 8091 = Familienassistent.
Smart Home

Wenn du rausrennst, reagiert das Haus

Bei jedem Phasenwechsel sendet das Einsatzfenster einen Webhook an Home Assistant. So färbt sich z. B. das Flurlicht rot, sobald der Melder geht — und geht nach dem Einsatz von selbst wieder aus.

Was der Mirror sendet

// POST an deinen HA-Webhook
{
  "state": 1,        // 1 Alarm · 2 im Einsatz
  "keyword": "B2 - Zimmerbrand",
  "unit": "Florian Musterstadt",
  "time": 1720000000000
}

state: 1 Alarm · 2 im Einsatz · 3 war im Einsatz · 0 Einsatz vorbei.

Automation in Home Assistant

trigger:
  - platform: webhook
    webhook_id: feuerwehr_alarm
    local_only: true
condition:
  - "{{ trigger.json.state == 1 }}"
action:
  - service: light.turn_on
    target:
      entity_id: light.flur_hue_go
    data:
      rgb_color: [255, 0, 0]
      brightness_pct: 100
Loslegen

Ein Befehl. Der Rest läuft von allein.

Auf dem Raspberry Pi klonen und starten — der Assistent installiert alles, fragt deine Daten ab und richtet den Autostart ein.

# auf dem Raspberry Pi
git clone https://github.com/ZombieEcki/LUMIRA.git ~/LUMIRA
cd ~/LUMIRA
chmod +x install.sh
./install.sh
Node.js & MagicMirror² installieren
beide Module + Abhängigkeiten
Standort, Kalender & News abfragen
config.js automatisch erzeugen
Autostart per pm2 (Wayland)
Neustart-fest — startet beim Booten
Später ändern: ./install.sh --reconfigure erzeugt die config.js neu — ohne Neuinstallation.
