ℹ️ Wie richte ich das in Home Assistant ein?

In Home Assistant unter Einstellungen → Automatisierungen → Neue Automatisierung einen Auslöser „Webhook" anlegen und die dort erzeugte URL hier eintragen. LUMIRA sendet dann bei jedem Alarmphasenwechsel {state, keyword, unit, time} per POST. Ausführliche Anleitung: docs/HOME_ASSISTANT.md im Projekt.
